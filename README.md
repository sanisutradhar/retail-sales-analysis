# Retail Sales and Customer Cohorts

## Project goal

Analyze retail transactions to identify sales trends, top products, and customer repeat-purchase patterns.

## Business questions

- How do monthly sales and order counts change over time?
- Which products generate the most sales?
- How many customers make repeat purchases?
- How does customer activity change after their first purchase?

## Dataset

This project uses the Online Retail II dataset from the
[UCI Machine Learning Repository](https://archive-beta.ics.uci.edu/dataset/502/online%2Bretail%2Bii/files).

Download the Excel workbook and place it at:

`data/raw/online_retail_II.xlsx`

The raw dataset is not included in this repository.
